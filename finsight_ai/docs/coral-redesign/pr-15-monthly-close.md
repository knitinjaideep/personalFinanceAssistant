# PR 15 — Monthly Coral Close

Implement a Monthly Financial Close experience.

This is a summary experience, not an accounting close.

For each completed month summarize:
- Income
- Needs
- Wants
- Savings
- Investments

For each:
- Target
- Actual
- Variance
- Status

Then show:
- What went well
- What needs attention
- Biggest drivers
- Goal progress
- Next month plan

Add access from Overview.

Prefer a dedicated page, drawer, or expandable report over a blocking popup.

Support historical monthly closes.

If derived dynamically, do not persist duplicate derived values unless caching is genuinely useful.

Add tests.
